## Goals

1. **Aqua Loading 改版為「分裂／合一」循環**：現行 aqua 載入指示器是單圈 conic-gradient 旋轉環（`aqua-loader`），改為 **1 顆 → 分裂為 2 → 再分裂為 4 → 收合回 1** 的循環動畫，延續 aqua 的毛玻璃／高光語彙。
2. **表格表頭去除逐 cell 毛玻璃**：aqua 主題下每個 `<th>` 各自套 `backdrop-blur-md`，每格都會成為獨立的 backdrop root 與合成層，欄數越多成本越高。
3. **DateRangeV2 的 deep watch 收斂**：`[Date, Date] | null` 這種淺結構不需要 `deep: true`。

**非目標**：不動其他三種主題的 Loading 造型；不調整 Table 的 sticky 欄位策略（除非採用下方 Q1 的選項 B）；不處理稽核清單剩餘的 `imports.dirs` 與 `Icons({ autoInstall })` 兩項。

## Architecture

### 1. Aqua Loading — 分裂／合一循環

`app/components/Camelot/Loading.vue:16` 現為 `.aqua-loader` + `.aqua-loader-ring`（conic-gradient + mask 的旋轉環）+ `.aqua-loader-core`。改為：

**方向：平面（2D）的分裂／合一循環**。原子造型（含所有 3D／球體變體）全部作廢。

- **結構（三層，讓「環繞」與「分裂」各自獨立）**：
    - `.aqua-split-spin`：最外層，整組以等速 `rotate` 持續公轉，是環繞感的來源。
    - `.aqua-split-branch`：每顆球一支「臂」，決定它在圓周上的角度；分裂時以角度位移把子球從母球身上岔開（第 3 顆自 0° 岔到 90°、第 4 顆自 180° 岔到 270°），四顆最終等分圓周。
    - `.aqua-split-ball`：球體本身，只負責沿臂的方向推進半徑（`translateX`）與縮放、淡入淡出。
    - 4 顆球固定存在於 DOM，分裂由位移／縮放／透明度演出，不動態增刪節點。
- **節奏：長停留 × 快移動**。整段時間主要花在「停在某個狀態」上，狀態之間的位移則短而俐落——每次轉換僅約 0.3s，其餘時間都在停留。停留與移動的時間曲線分開指定（於各 keyframe 內以 `animation-timing-function` 切換），停留段為 `linear`（實際上不變動），分裂段用爆發曲線 `cubic-bezier(.08,1.25,.3,1)`（起步極快、末段輕微過衝再收住）、蓄力段用漸強曲線 `cubic-bezier(.5,0,.78,.6)`，收合段用加速曲線 `cubic-bezier(.55,0,.9,.55)`。
- **循環**（3.6s／循環，公轉 `linear` 每循環 3 圈＝約 300°/s）。**合一後不回落：膨脹到頂點即直接炸開，像花火**：
    1. **炸開為 2**（0–8%）：週期起點就是上一輪蓄力的頂點（scale 1.5、濃度全滿）。主球不收縮回原尺寸，而是直接以爆發曲線 `cubic-bezier(.08,1.25,.3,1)`（起步極快、末段**輕微過衝再收住**，模擬火花被拋出的慣性）向外拋射；第 2 顆自同一點分出，兩顆沿相對的臂推進至半徑約 27px 並縮小至 .82。因為外層仍在公轉，拋射軌跡是**螺旋而非直線**。
    2. **停留 2 顆**（8–26%）。
    3. **蓄力膨脹（第二處）**（26–36%，約 0.36s）：兩顆**留在原半徑上**同步膨脹（.82 → 1.08、濃度略升），採與第 6 步相同的漸強曲線。分裂前必先蓄力，是本動畫的一致語彙。
    4. **炸開為 4**（36–44%）：自膨脹頂點直接以爆發曲線拋射，第 3、4 顆自母球位置分出並以角度岔開，四顆推進至半徑約 41px、縮小至 .6，形成等分圓周的環繞。
    5. **停留 4 顆**（44–74%，全循環最長的停留）。
    6. **合回 1**（74–84%，加速旋入）：四顆一邊繼續公轉一邊旋回中心，收合段採 `cubic-bezier(.55,0,.9,.55)` 越靠近中心越快，像被吸進去。**外圍三顆維持該階段的濃度不提前淡出**，只在與主球完全重合的那一瞬（約 85%）才切掉。
    7. **蓄力膨脹（第一處）**（84–100%，約 0.58s，全循環最長的轉換段）：主球自 .6 一路膨脹至 **1.5**、濃度回到全滿，**不設回落**。曲線採漸強的 `cubic-bezier(.5,0,.78,.6)`——起始慢、越接近頂點越快，讀起來是「蓄力」而非單純放大；此狀態與 0% 完全相同，因此頂點無縫接回步驟 1 的炸開。整個循環沒有任何「靜止的一顆球」，能量從吸收直接轉成下一次爆發。
- **合併必須讀起來像合併**：初版讓外圍球在半路淡出，看起來是「三顆消失、剩下一顆」而非「四顆併成一顆」。修正的關鍵有三：① 途中不淡出，透明度只在完全重合的瞬間切換；② 收合採加速曲線，像被吸進去而不是慢慢飄回；③ 吸收的能量不洩掉，直接轉為下一輪的蓄力膨脹。
- **尺寸遞減**：1 顆時最大、2 顆時中、4 顆時最小（蓄力峰值 1.5 → 2 顆 .82 → 4 顆 .6），讓「總量守恆」的分裂語意成立，而不是憑空多出球。
- **濃度遞減**：透明度隨分裂次數遞增——1 顆時最實（1）、2 顆時較淡（.85）、4 顆時最淡（.62），合併回 1 顆時恢復為最實。下限刻意不壓太低，4 顆階段仍須清楚可見。與尺寸遞減同一套邏輯：同一份量被分得越細，每一份就越小也越淡；合併則同時還原尺寸與濃度。
- **球體外觀**：填色走色彩角色（`color-mix(in srgb, var(--cml-color-current-color, var(--color-primary)) 88%, white)`），搭配頂端 inset 白色高光與同色外暈。**不使用 `backdrop-filter`**：載入遮罩本身是半透明黑底，surface 色在深色模式下幾乎與遮罩同色，球會看不見；改為不透明填色後毛玻璃也失去意義，一併省下該層合成。
- **色彩**：一律走既有色彩角色變數 `var(--cml-color-current-color, var(--color-primary))`，不引入新的硬編碼色值（呼應 code-style「減少 Arbitrary Values」）。
- **效能**：動畫只使用 `transform` 與 `opacity`（可交由合成器處理），不動 `width`/`box-shadow` 等會觸發重繪的屬性。
- **無障礙**：新增 `@media (prefers-reduced-motion: reduce)` 區塊停用公轉與分裂、只保留一顆靜態球（與 `Drawer.vue:154`、`RevealText.vue:100` 的既有作法一致）。

## Key Decisions

- **[使用者最終決定]** Aqua Loading 採**平面（2D）**構圖，不使用 `perspective` 或 3D 旋轉 — 理由：Phase 2 期間曾依序要求 2.5D → 球體 → 中心與電子皆為球 → 實心球感，逐案預覽後使用者決定回到平面。前述 3D 方案（2.5D 傾斜軌道、線框球、實心核球）全部作廢，不留在實作範圍內。
- **[使用者回饋]** 球體改用色彩角色填色、移除 `backdrop-filter`，並把濃度下限由 .5 提高到 .62 — 理由：初版沿用 `--color-surface` 的 62% 半透明填色，在深色模式下與載入遮罩幾乎同色，加上分裂階段的低透明度後幾乎看不見。改為不透明的角色色後毛玻璃已無作用，順帶省下一層合成。
- **[使用者最終決定]** 放棄原子造型，改為「1 → 2 → 4 → 回到 1」的分裂／合一循環 — 理由：使用者於 Phase 2 最終指定。原子方向（含靜止軌道 + 等速錯相的修正版）不再列入實作範圍。
- **[使用者指定]** 分裂／合一須帶**環繞移動**感 — 理由：使用者於 Phase 2 追加；實作以「外層等速公轉 × 內層推進半徑」的三層結構達成，球體進出中心的軌跡因此是螺旋而非直線，四顆時等分圓周。
- **[Q2]** 公轉採每循環 3 圈（約 300°/s） — 理由：使用者先在 360°／720° 中選定 720°，其後週期拉長，為維持角速度再提高至 3 圈。
- **[使用者回饋]** 合併段重做：外圍球途中不淡出、改為加速旋入、主球於重合瞬間彈一下 — 理由：初版在半路淡出，讀起來是「三顆消失只剩一顆」而不是「四顆併回一顆」；透明度只在完全重合的瞬間切換才不會被察覺。
- **[使用者指定]** 透明度隨分裂次數遞增（1 顆 .95 → 2 顆 .72 → 4 顆 .5），合併後還原 — 理由：使用者於 Phase 2 追加；與既有的尺寸遞減同屬「總量守恆」語意，兩者一起變化才不會互相矛盾。
- **[使用者指定]** 節奏改為「每個階段停留拉長、階段之間的移動要快」 — 理由：使用者於 Phase 2 釐清；先前把整段等比例放慢反而讓移動變鈍。實作上把停留與移動的時間曲線分開（於 keyframe 內個別指定 `animation-timing-function`），停留佔去大部分時間，每次轉換僅約 0.3s。
- **[執行中]** 公轉圈數隨週期一起提高（每循環 3 圈以上）— 理由：週期拉長後若維持 720°，角速度會下降，與「速度要快」相牴觸；提高圈數才能同時滿足長停留與快環繞。
- **[Q2 + 使用者追加]** 採 V 案（3.6s／循環、轉 3 圈），且合一的彈跳直接接續下一輪分裂、1 顆狀態不另設停留 — 理由：使用者指定；實作上把峰值放在 0%／100% 兩端使其等值，循環得以無縫銜接，停留時間全部留給 2 顆與 4 顆兩個狀態。
- **[使用者指定]** 2 → 4 的分裂前也要有蓄力膨脹 — 理由：使用者於 Phase 2 追加；兩處分裂使用同一套「蓄力 → 爆開」語彙，動畫才有一致的因果關係，而不是只有第一次爆開有前置動作。膨脹在原半徑上進行（不位移），時間由 2 顆的停留段讓出。
- **[使用者指定]** 蓄力膨脹的時間拉長至約 0.5s（原約 0.25s），並改用漸強曲線 — 理由：使用者於 Phase 2 追加；膨脹太快會讓「蓄力」讀不出來，變成只是爆開前的一個瞬間。時間由 4 顆停留段讓出，循環總長維持 3.6s。
- **[使用者指定]** 爆開幅度加大：蓄力峰值 1.25 → **1.5**，2 顆半徑 22 → 27px、4 顆半徑 31 → 41px，並在爆發曲線末段加入輕微過衝再收住 — 理由：使用者於 Phase 2 追加；連帶把 loader 外框由 96px 提高到 112px（見 Q3），否則 4 顆散開時會貼邊。
- **[使用者指定]** 彈跳**不回落**，膨脹到頂點直接炸開，取花火意象 — 理由：使用者於 Phase 2 最終追加；先前的「彈一下再收回 1.0 才分裂」多了一個洩力的動作，讀起來是落地而非爆發。改為蓄力（.6 → 1.5）→ 頂點即拋射，分裂段換上起步極快的爆發曲線，能量從吸收直接轉成下一次爆開，全循環沒有靜止的一顆球。
- **[執行中]** 環繞、角度岔開、半徑推進拆成三層各自動畫 — 理由：三者的時間曲線不同（公轉 linear、分裂 ease-in-out），混在同一組 keyframes 會互相牽制且難以調整。
- **[執行中]** 四顆球固定存在於 DOM，分裂以位移／縮放／透明度演出，不動態增刪節點 — 理由：新增刪除節點會觸發版面重算，且無法用純 CSS keyframes 表達；固定節點則整段動畫都留在合成階段。
- **[執行中]** 分裂時球體尺寸遞減（1 → .8 → .62）— 理由：讓「一分為二」讀起來是同一份量被分開，而非憑空生出新球。
- **[執行中]** 計畫 `${description}` 由 `aqua-quantum-loader-...` 改為 `aqua-split-merge-loader-...` — 理由：資料夾名即索引，概念既已更換，名稱必須跟著改才找得回來（分支與 issue 皆尚未建立，改名無外部影響）。
