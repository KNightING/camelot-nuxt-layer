# 排程主題

## Summary

`useCamelotSchedulerTheme()` 集中 Scheduler 各視圖的五主題樣式，回傳 `containerClass`、`lineClass`、`headerTextClass`、`todayClass`、`todayNumberClass`、`eventClass`、`draftClass`、`lockedClass`、`nowLineClass` 與 `easeClass`。

## 外觀
| 主題 | 外框 | 事件 |
| :--- | :--- | :--- |
| tactile | 實心表面 | 角色色填滿，圓角 |
| aqua | 玻璃面板 | 玻璃填色 |
| scifi | 直角、主色邊框、等寬字 | 角色色框線加淡底與外發光 |
| cupertino | surface 底，大圓角 | 當前色實心底 |
| material | surface 底加邊框 | 左側粗線加淡底 |
