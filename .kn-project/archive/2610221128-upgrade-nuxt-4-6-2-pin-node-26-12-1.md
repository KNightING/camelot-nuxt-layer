# 2610221128 - upgrade-nuxt-4-6-2-pin-node-26-12-1

- Created: 2026-10-22 11:28 / Archived: 2026-10-22 12:10
- Issue: KNightING/camelot-nuxt-layer#60
- Milestone: 4.6.2.0 / Base Branch: 4.6.2.0

## Summary
將 nuxt 由 4.6.1 升級至 4.6.2，並把三個 Dockerfile 的 Node 版本由浮動的 `26-alpine` 釘選為 `26.12.1-alpine`。
因應 Node.js 2026 年 10 月安全性釋出（https://nodejs.org/en/blog/vulnerability/october-2026-security-releases）。影響依賴與建置設定，無程式邏輯變更；lint、typecheck、build 皆通過。

## Cross-Repo Scope
無（單一 repo）

## Key Decisions
- **[Milestone]** 使用者選定 `4.6.2.0`（非標準四段格式，沿用 tag 慣例），版本分支 `4.6.2.0` 自 `main` 切出；Rule 24 非標準格式跳過版本檔同步與 Version Gate。
- **[整合主幹]** 遠端僅有 `main`，`${DEFAULT_BRANCH}` = `main`，不詢問。
- **[執行中]** 本地 main 落後 origin/main，實際起點 nuxt 為 4.6.1 而非 4.5.2；計畫已更正，目標版本不變。
- **[Node 釘選]** 採 `26.12.1-alpine`，三個 Dockerfile 維持各自 `ARG NODE_VERSION` 結構，僅改預設值。

## Deviations
計畫初稿以過期的本地 main 為基準（誤記起點 4.5.2、`package.json:49`），執行時更正為 4.6.1、`package.json:52`；其餘依計畫。

## Impact Files
- `package.json:52` (`dependencies.nuxt`) — `4.6.1` → `4.6.2`
- `pnpm-lock.yaml` — nuxt 及 `@nuxt/*` 相依 4.6.1 → 4.6.2
- `Dockerfile:3`、`Dockerfile.ssr:3`、`Dockerfile.spa:10` (`ARG NODE_VERSION`) — `26-alpine` → `26.12.1-alpine`
